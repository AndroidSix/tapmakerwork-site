01

可视化与 Runtime

把最终效果和编辑操作放在同一画布，减少改完再盲猜的循环。

  • 真 Runtime 视图：最终帧 + 控件命中框叠加
  • 活编：拖移、八向缩放、键盘微调、属性面板
  • *.ui.json 视觉草稿；Lua 负责行为
  • Cocos 风格变换快捷键与多选吸附
  • 可选项目适配器，入口自动备份
02

项目与交付

从打开项目到构建就绪，状态与证据一条线可见。

  • 原创交付工作台：阶段 / Runtime / 构建就绪度
  • VS Code 风格 Git：暂存、提交、同步、提交图谱
  • 语义资产审计与全项目 UI 发现
  • 官方 Preview 状态、日志与生命周期适配
  • 显式远程构建与测试码流程
03

桌面与 AI

桌面宿主 + 项目级 MCP，让 AI 读项目与控件，而不是乱敲 Shell。

  • Electron 宿主，macOS / Windows 安装包
  • 发行更新走 GitHub 主仓，支持手动下载回退
  • 项目 MCP：文件、转换、快照、Runtime、预览与构建
  • 离线内置 Monaco 编辑器，无 CDN 依赖
  • 系统 Node.js 发现（PATH / 登录 shell / Homebrew / Volta）
04

安全边界

增强官方工作流，而不是替换或重分发官方安装包。

  • 不修改官方 Maker 安装
  • Shell 面板在沙箱验证前有意禁用
  • 适配器只写受管 hook，并备份原入口
  • MCP 不提供通用 shell
  • 商标归 TapTap 及相关权利人所有

BOUNDARY

请先读清产品边界

这是社区增强工具，不是 TapTap 官方 IDE，也不分发官方安装包。

  • 非官方产品 在官方 Maker CLI / Runtime 之上做可视化与交付增强。
  • 不修改官方安装 预览、构建、测试码仍依赖你本机的官方环境。
  • 适配器可选且可回退 只写受管 hook，原入口备份到 .tapmakerwork/backups。
  • 赞助自愿 MIT 开源，不设付费墙；赞助不绑定任何功能或授权。
